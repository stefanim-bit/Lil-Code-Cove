Designer Feedback Guide

How to review the practice scenarios and get your changes made. No coding or GitHub needed.

1

Open a scenario

Go back to the file list (the page this guide is on). Click a folder, then click the file ending in .html. It opens as a working scenario.

Current versions live in folders named Current. Ignore Previous Versions and files with copy in the name unless you are asked to look at them.

2

Click through every path

Try each reply choice, including the "wrong" ones, until you reach the end. Look at text, colors, spacing, images, and buttons on every screen.

After any change is made, refresh the page to see it.

3

Write your feedback, one note per issue

Every note should say which scenario, which screen, what you see, and what you want instead.

Good: "Wire Transfer, first screen, Lena's speech bubble: the text is too small. Please make it a bit bigger and add more space between the four reply buttons."
Hard to act on: "The first screen looks off."

Screenshots help a lot. Circle or arrow the thing you mean.

4

Type your notes into the Base44 chat

Open the chat on the left of the app and paste your notes for one scenario. Send everything for that scenario in one message. You can attach screenshots.

Before you send, check that the project owner isn't mid-request in the chat. Only one person should ask for changes at a time, so two people don't change the same file at once.

5

Base44 makes the changes

Wait for it to say it's done, then refresh the scenario in the preview.

6

Review the result and repeat

Refresh the scenario and check your notes one by one. If something is still off, send a new note in the chat, written the same way as step 3.

7

Approve

When you are happy, tell the project owner "approved". The owner then merges the pull request, which saves the final version to the main project.

Tip: keep each round small, one scenario at a time. It is easier to check and easier to undo if needed.
