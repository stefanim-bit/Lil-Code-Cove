Collaborative Feedback Tool

How to Use This Tool

  1. Open a project below and click through it to test.
  2. To leave a comment, click the "Give feedback" button, then click the element you'd like to leave a comment on. Please be as specific as possible, like: "Make this text bigger and add more space between the reply buttons."
  3. Type your comment, click "Post comment", and enter your name. Comments (top right) shows what everyone has posted.

That's it, you're done!

For Amber (design): turning comments into changes
  1. Review comments. Go to Manage (home page, top right), sign in, and open the Comments tab. Use the filter to see Open comments. Each links to its file.
  2. Pick what to change. On the project page, click Comments, tick "Design team", and use Show to jump to the element. To request a change, click Give feedback on it and choose Copy note for Base44.
  3. Paste the note into the Base44 chat and send it. Several notes for one project can go in one message. Keep rounds small: one project at a time.
  4. Check the result, then mark the comment Resolved.
  5. Approve. Tell the project owner "approved" so they merge the pull request.

Inspect (top right) shows an element's font, size, colors and spacing. Click to lock, Esc to exit. In Manage you also choose which projects appear on the home page.
