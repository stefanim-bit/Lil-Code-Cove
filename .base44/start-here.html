START HERE: how to review and request changes

No coding or GitHub needed. The scenario files are listed below this guide.

  1. Open a scenario. In the list below, click a folder, then a file ending in .html. Use the folders named Current. Ignore Previous Versions and files with "copy" in the name unless asked.
  2. Click through every path. Try every reply choice, including the "wrong" ones, until the end. Check text, colors, spacing, images, and buttons on each screen.
  3. Write one note per issue. Say which scenario, which screen, what you see, and what you want instead. Screenshots help.
    Good: "Wire Transfer, first screen, Lena's speech bubble: text is too small. Make it bigger and add space between the four reply buttons."
    Hard to act on: "The first screen looks off."
  4. Paste your notes into the Base44 chat (left side of the app). Send everything for one scenario in one message. Only one person should send requests at a time, so check the project owner isn't mid-request.
  5. Wait for Base44 to say it's done, then refresh the scenario.
  6. Review and repeat. If something is still off, send a new note in the chat, written the same way as step 3.
  7. Approve. Tell the project owner "approved". The owner merges the pull request, which saves the final version to the main project.

Tip: keep each round small, one scenario at a time.
