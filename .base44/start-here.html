START HERE: how to review and request changes

No coding or GitHub needed. The scenarios are listed above this guide.

  1. Open a scenario. Click a card in the Scenarios list above to open it directly. Older versions are tucked under each session. The full folder list is under Browse all folders.
  2. Click through every path. Try every reply choice, including the "wrong" ones, until the end. Check text, colors, spacing, images, and buttons on each screen.
  3. Point at what you want changed. On the scenario page, click the blue Give feedback button (bottom right). Click the exact thing you mean, such as a speech bubble or a reply button. Type what should change, then click Copy note. The note already includes the scenario, screen, and element.
    Good comment: "Make this text bigger and add more space between the reply buttons."
    Hard to act on: "This looks off."
    Other buttons at the bottom right: Inspect shows an element's font, size, colors and spacing as you hover (click to lock, Esc to exit). Comments opens the shared list. After picking an element you can Post comment (everyone sees it, grouped by person) or Copy note for Base44 to request a change in chat. Design team: tick "Design team" in the Comments panel to resolve or delete.
    Make one note per issue. If the copy button doesn't work, select the text shown in the box and copy it yourself.
  4. Paste the note into the Base44 chat (left side of the app) and send it. You can paste several notes for one scenario in one message. Only one person should send requests at a time, so check the project owner isn't mid-request.
  5. Wait for Base44 to say it's done, then refresh the scenario.
  6. Preview and confirm. Check the change. If it's right, reply "confirmed". If not, use Give feedback on the same element again and say what to adjust.
  7. Approve. Tell the project owner "approved". The owner merges the pull request, which saves the final version to the main project.

Tip: keep each round small, one scenario at a time.
