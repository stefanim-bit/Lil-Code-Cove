# Handoff Instructions — Practice Session Sims

General, cross-scenario guidance for starting a fresh chat to build the next scenario. Anything specific to one scenario (its correct/distractor articles, scoring, market rules, escalation confirmations) lives with that scenario's own matrix and fact-check doc — not here.

## Matrix hyperlinks
Article and resource names in the routing & scoring matrix can be hyperlinked to their CSI / Help Center URLs. This is deferred by default — add links in a final pass once the article set for the scenario is locked.
